# Street Rider

Top-down endless traffic-riding game for Android (pure Java, no dependencies).

**Controls:** `W` gas · `S` brake · `A`/`D` steer (arrow keys work too) — or the on-screen buttons on a phone.
Weave through traffic, pass cars close at speed for **NEAR MISS** bonuses.

Download the APK from [Releases](../../releases).

Build: `./gradlew assembleRelease`
